# Code of Conduct

This project uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

All maintainers, contributors and participants must obey it. It applies in all project spaces: issues, pull requests, discussions and other channels.

## Report a problem

To report unacceptable behaviour, send an email to the maintainer at CONTACT_EMAIL.

The maintainer will examine all reports. The maintainer will keep the identity of the reporter confidential.
